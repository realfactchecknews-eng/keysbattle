# КейсБатл.рф

Рофл-кейсы CS2 для друзей. Без реальных денег — баланс, инвентарь и статистика в localStorage.

- **Кейсы** — 14 штук (рофл / оружейные / премиум), режимы прокрутки: лента, барабан, быстро; до x5 за раз
- **Кейс-батлы** — до 8 раундов, 1v1…1v1v1v1 против ботов, победитель забирает всё
- **Апгрейд** — до 6 скинов в ставку, колесо с зоной «снизу/сверху», быстрый режим
- **Контракты** — 3–10 скинов → один случайный на x0.15–x3.5
- Уровни (бонус растёт), звуки WebAudio, конфетти, live-лента дропов

Модели скинов: Steam CDN через [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API) (`data.js`). Цены вымышленные, считаются от редкости.
