# КейсБатл.рф

Кейсы CS2 для друзей без реальных денег. Баланс, инвентарь и статистика — в localStorage.

- **Цены** — рыночные (Skinport, $1 = 90 монет), отдельно для каждого износа и StatTrak™
- **Кейсы** — 42 официальных кейса CS2 с оригинальными картинками + 25 тематических от 12 до 360 000 монет (окупаемость 90%)
- **Шансы** — официальные для CS2 (79.92 / 15.98 / 3.2 / 0.64 / 0.26%), float равномерно в диапазоне скина, StatTrak 10%
- **Рандом** — `crypto.getRandomValues`, вероятность каждого предмета показана на странице кейса
- **Апгрейд** — шанс = ставка / цель, без комиссии
- **Контракты** — 3–10 предметов → результат x0.15–x3.55, в среднем ровно x1.00
- **Фарм** — +100 монет за клик
- **Батлы** — до 8 раундов, до 4 игроков

Данные: [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API) + Skinport API → `data.js`.
